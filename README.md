# DSU Chat UI

A simple chatbot interface built with plain HTML and CSS.

## What I practised
- Flexbox layout (sidebar + chat area)
- Styling buttons, lists and an input box
- Hover and focus effects
- A media query to hide the sidebar on small screens

## Folder structure
```
index.html
style.css
images/   (plus-icon, search-icon, message-icon, send-icon, user)
```

## Run it
Open `index.html` in your browser or use Live Server in VS Code.
